# Sales Performance Analysis

## Project Overview

This project analyzes sales data using Python and Power BI.
The project provides insights into sales, profit, quantity, products,
categories, and regions through data analysis and interactive visualization.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Power BI
- CSV

## Key Analysis

- Total Sales
- Average Sales
- Total Profit
- Total Quantity
- Product-wise Sales
- Product-wise Profit
- Category-wise Sales
- Region-wise Sales
- Category-wise Sales Distribution

## Power BI Dashboard

The interactive Power BI dashboard includes:

- Sales KPI
- Average Sales KPI
- Profit KPI
- Quantity KPI
- Product-wise Sales Chart
- Product-wise Profit Chart
- Category-wise Sales Chart
- Region-wise Sales Chart
- Category-wise Sales Distribution
- Region, Category and Order Date Filters

## Project Files

- `sales_analysis.py` – Python data analysis script
- `sales_data.csv` – Sales dataset
- `Sales-Performance-Dashboard.pbix` – Power BI dashboard

## Conclusion

This project demonstrates how Python and Power BI can be used together
for sales data analysis, visualization, and business insights.
